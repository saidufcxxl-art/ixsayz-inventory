# IXSAYZ Inventory

Мобильное PWA-приложение для складского учета: поставщики, завозы, товары, EAN-13 штрихкоды, PDF-ценники 43 x 25 мм, PDF-отчеты и экспорт в CSV/XLSX для кассы.

## Что внутри

- Firebase Auth: вход, регистрация, выход.
- Firestore: отдельная база данных каждого пользователя по пути `users/{uid}/...`.
- Поставщики: создание, редактирование, удаление, карточка поставщика.
- Поставки: создание завоза, строки товаров, суммы закупки/продажи/прибыли.
- Товары: поиск, фильтры, карточка, редактирование, удаление.
- EAN-13: генерация уникального кода и проверка контрольной цифры.
- PDF-ценники: размер 43 мм x 25 мм, поддержка `labelQty`.
- PDF-отчеты: по поставке, по поставщику, общий отчет.
- Экспорт: CSV UTF-8 с `;`, CSV UTF-8 с `,`, XLSX.
- PWA: manifest, service worker, иконки, запуск через GitHub Pages.

## Структура Firestore

```text
users/{uid}/suppliers/{supplierId}
users/{uid}/deliveries/{deliveryId}
users/{uid}/products/{productId}
users/{uid}/categories/{categoryId}
users/{uid}/settings/main
```

Все создаваемые документы получают `id`, `userId`, `createdAt`, `updatedAt`.

## Быстрый запуск

1. Создайте Firebase проект.
2. Включите Authentication Email/Password.
3. Создайте Firestore Database.
4. Вставьте правила из `FIREBASE_SETUP.md`.
5. Скопируйте Firebase config в `firebase.js`.
6. Загрузите файлы проекта в GitHub repository.
7. Включите GitHub Pages для ветки `main` и папки `/root`.
8. Откройте ссылку Pages на телефоне.
9. На iPhone нажмите Share -> Add to Home Screen.
10. На Android откройте меню браузера -> Add to Home screen / Install app.

## Как добавить первого поставщика

1. Зарегистрируйтесь или войдите.
2. На главном экране нажмите `Добавить поставщика`.
3. Заполните код, например `P1`, название, телефон и комментарий.
4. Нажмите `Сохранить`.

## Как добавить первый завоз

1. Откройте `Поставки`.
2. Нажмите `Добавить завоз`.
3. Выберите поставщика, дату и номер поставки.
4. Заполните строки товаров.
5. Если поле штрихкода пустое, приложение создаст EAN-13 автоматически.
6. `labelQty` по умолчанию равен количеству товара.
7. Нажмите `Сохранить завоз`.

## Как создать PDF ценников

1. Откройте `Печать`.
2. Выберите поставку, поставщика или отдельные товары.
3. Нажмите `Создать PDF ценников`.
4. На iPhone приложение попробует открыть системное меню Share. Если оно недоступно, PDF будет скачан.

## Как экспортировать товары для кассы

1. Откройте раздел `Экспорт` через кнопку на главном экране.
2. Выберите объем: все товары, поставка, поставщик или выбранные товары.
3. Выберите формат CSV `;`, CSV `,` или XLSX.
4. Нажмите `Скачать экспорт`.

В CSV штрихкод сохраняется как текстовая Excel-формула вида `="2900000000008"`, чтобы Excel не съедал цифры.

## iPhone: если PDF не скачивается

- Откройте приложение в Safari, не во встроенном браузере мессенджера.
- Разрешите всплывающие окна и скачивания для сайта.
- Используйте кнопку Share, если Safari показывает системное меню.
- Если файл открылся в новой вкладке, нажмите Share -> Save to Files.

## Если Firebase не подключился

- Проверьте, что `firebase.js` заполнен полностью.
- Убедитесь, что `projectId`, `authDomain` и `appId` взяты из одного Firebase проекта.
- Проверьте, что Email/Password включен в Authentication.
- Проверьте, что Firestore создан и правила опубликованы.
- Откройте консоль браузера и посмотрите текст ошибки Firebase.

## Важное ограничение проверки

Код приложения проверен локально: синтаксис JS, бизнес-логика EAN-13, расчеты, CSV, структура файлов и отсутствие localStorage. Реальные вход/регистрация/Firestore-синхронизация требуют вашего Firebase config и опубликованного проекта Firebase.
