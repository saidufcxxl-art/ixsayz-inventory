# IXSAYZ Inventory

Личное мобильное PWA-приложение для складского учета: поставщики, завозы, товары, EAN-13 штрихкоды, PDF-ценники 43 x 25 мм, PDF-отчеты и экспорт в CSV/XLSX для кассы.

## Важный режим работы

Приложение сейчас работает **без регистрации и пароля**. Открыл ссылку или иконку на телефоне — сразу попал в склад.

Данные при этом не хранятся в localStorage. Все поставщики, поставки и товары сохраняются в Firebase Firestore в одной личной базе:

```text
users/public/suppliers/{supplierId}
users/public/deliveries/{deliveryId}
users/public/products/{productId}
users/public/categories/{categoryId}
users/public/settings/main
```

Это удобно для личного использования. Но ссылка на GitHub Pages фактически открывает приложение без защиты. Если позже приложение нужно будет продавать, давать сотрудникам или разделять данные разных людей, надо вернуть Firebase Auth и правила `users/{uid}/...`.

## Что внутри

- Firestore: одна личная база `users/public/...`.
- Поставщики: создание, редактирование, удаление, карточка поставщика.
- Поставки: создание завоза, строки товаров, суммы закупки/продажи/прибыли.
- Товары: поиск, фильтры, карточка, редактирование, удаление.
- EAN-13: генерация уникального кода и проверка контрольной цифры.
- PDF-ценники: размер 43 мм x 25 мм, поддержка `labelQty`.
- PDF-отчеты: по поставке, по поставщику, общий отчет.
- Экспорт: CSV UTF-8 с `;`, CSV UTF-8 с `,`, XLSX.
- PWA: manifest, service worker, иконки, запуск через GitHub Pages.

## Быстрый запуск через GitHub Pages

1. Создайте Firebase проект.
2. Создайте Firestore Database.
3. Вставьте открытые правила из `FIREBASE_SETUP.md`.
4. Проверьте, что Firebase config вставлен в `firebase.js`.
5. Загрузите файлы проекта в GitHub repository.
6. Включите GitHub Pages для ветки `main` и папки `/root`.
7. Откройте ссылку Pages на телефоне.
8. На iPhone нажмите Share -> Add to Home Screen.
9. На Android откройте меню браузера -> Add to Home screen / Install app.

## Как добавить первого поставщика

1. Откройте приложение.
2. На главном экране нажмите `Добавить поставщика`.
3. Заполните код, например `P1`, название, телефон и комментарий.
4. Нажмите `Сохранить`.

## Как добавить первый завоз

1. Откройте `Поставки`.
2. Нажмите `Добавить завоз`.
3. Выберите поставщика, дату и номер поставки.
4. Заполните строки товаров.
5. Если поле штрихкода пустое, приложение создаст EAN-13 автоматически.
6. `labelQty` по умолчанию равен количеству товара.
7. Нажмите `Сохранить завоз`.

## Как создать PDF ценников

1. Откройте `Печать`.
2. Выберите поставку, поставщика или отдельные товары.
3. Нажмите `Создать PDF ценников`.
4. На iPhone приложение попробует открыть системное меню Share. Если оно недоступно, PDF будет скачан.

## Как экспортировать товары для кассы

1. Откройте раздел `Экспорт` через кнопку на главном экране.
2. Выберите объем: все товары, поставка, поставщик или выбранные товары.
3. Выберите формат CSV `;`, CSV `,` или XLSX.
4. Нажмите `Скачать экспорт`.

В CSV штрихкод сохраняется как текстовая Excel-формула вида `="2900000000008"`, чтобы Excel не съедал цифры.

## Если Firebase не сохраняет данные

- Проверьте, что Firestore создан.
- Проверьте, что правила из `FIREBASE_SETUP.md` опубликованы.
- Проверьте, что `firebase.js` содержит правильный `projectId`.
- Если в консоли ошибка `permission-denied`, почти всегда проблема в правилах Firestore.

## Как потом вернуть регистрацию

Когда приложение нужно будет дать другим людям или продавать, надо вернуть:

- Firebase Authentication Email/Password.
- Путь данных `users/{uid}/...` вместо `users/public/...`.
- Правила, где пользователь видит только свои документы.

Заготовка `js/auth.js` оставлена в проекте, поэтому вернуть авторизацию можно без полной переделки.
